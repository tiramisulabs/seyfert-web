The Seyfert ecosystem provides additional packages for common needs.

If you want to build one of these packages yourself, start with [Plugins](/guide/plugins/using). That section covers `createPlugin(...)`, `definePlugins(...)`, services, requirements, runtime hooks, lifecycle work, and diagnostics.

## Official & Community Packages

| Package | Type | Purpose | Install |
| --- | --- | --- | --- |
| `@slipher/logger` | Plugin | Request-aware logging helpers | `pnpm add @slipher/logger` |

## Plugins, Adapters, And Utilities

A plugin is installed in `new Client({ plugins: [...] })` and is composed by Seyfert. It can add client helpers, context helpers, lifecycle work, commands, components, modals, events, middlewares, or option fragments.

An adapter swaps infrastructure such as cache, REST, HTTP, gateway, or storage behavior. A plugin can use an adapter, but the adapter itself is not the plugin contract.

A utility exports functions, classes, decorators, or helpers that users import manually. Utilities are still useful; they just do not need plugin lifecycle unless they are being composed by the client.

## Custom Decorator Factory

You can create reusable decorators that assign metadata to command instances:

```ts
import type { Instantiable } from 'seyfert';

interface CustomOptions {
    cooldown?: number;
    category?: string;
    onlyDeveloper?: boolean;
}

export function MyOptions<A extends Instantiable<any>>(
    options: CustomOptions,
): (target: A) => A {
    return (target: A) =>
        class extends target {
            constructor(...args: any[]) {
                super(...args);
                Object.assign(this, options);
            }
        } as A;
}
```

Usage on commands:

```ts
import { Command, Declare, type CommandContext } from 'seyfert';

@Declare({ name: 'eval', description: 'Evaluate code' })
@MyOptions({ cooldown: 10, category: 'developer', onlyDeveloper: true })
export default class EvalCommand extends Command {
    async run(ctx: CommandContext) { /* ... */ }
}
```

## Context Extension

Add custom properties and methods available in all command/component contexts:

```ts
import { extendContext, Client } from 'seyfert';

const extended = extendContext((interaction) => ({
    startedAt: Date.now(),
    getLocale: () => interaction.locale ?? 'en',
}));

const client = new Client({ context: extended });
```

Module augmentation for type safety:

```ts
declare module 'seyfert' {
    interface ExtendContext extends ReturnType<typeof extended> {}
}
```

Usage in commands: `ctx.startedAt`, `ctx.getLocale()`.

For a dedicated guide on extending the command context, see [Extending CommandContext](/guide/learn/commands/extend-commandcontext).
