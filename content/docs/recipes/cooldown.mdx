title: Cooldown
---

`@slipher/cooldown` is a Seyfert plugin for per-command cooldowns.

```bash copy title="Installing..."
pnpm add @slipher/cooldown
```

## Plugin Setup

Install it like any other plugin:

```ts
import { Client, definePlugins } from 'seyfert';
import { cooldown } from '@slipher/cooldown';

const cooldownPlugin = cooldown();
const plugins = definePlugins(cooldownPlugin);

declare module 'seyfert' {
    interface SeyfertRegistry { plugins: typeof plugins }
}

const client = new Client({
    plugins,
});
```

The plugin exposes one `CooldownManager` on `client.cooldown` and `ctx.cooldown`. Storage is backed by the client's cache adapter.

## Declaring Cooldowns

Use the `@Cooldown` decorator on commands.

```ts
import { Command, type CommandContext, Declare } from 'seyfert';
import { Cooldown } from '@slipher/cooldown';

@Declare({ name: 'ping', description: 'Ping' })
@Cooldown.user(5_000)
export default class PingCommand extends Command {
    async run(ctx: CommandContext) {
        await ctx.write({ content: 'Pong!' });
    }
}
```

Decorator shortcuts cover the common scopes:

```ts
@Cooldown.user(5_000)
@Cooldown.guild(60_000, { default: 5 })
@Cooldown.channel(10_000)
@Cooldown.global(1_000)
@Cooldown.custom((ctx) => `${ctx.guildId}:${ctx.author.id}`, 5_000)
```

## Middleware

Enable the built-in middleware when you want Seyfert to stop commands that are cooling down:

```ts
const cooldownPlugin = cooldown({ middleware: true });
```

The default middleware name is `cooldown`, and the package registers that name for TypeScript, so commands can reference it directly:

```ts
import { Command, type CommandContext, Declare, Middlewares } from 'seyfert';
import { Cooldown } from '@slipher/cooldown';

@Declare({ name: 'ping', description: 'Ping' })
@Cooldown.user(5_000)
@Middlewares(['cooldown'])
export default class PingCommand extends Command {
    async run(ctx: CommandContext) {
        await ctx.write({ content: 'Pong!' });
    }
}
```

Register it globally when every command should pass through cooldown handling:

```ts
const cooldownPlugin = cooldown({
    middleware: { global: true },
});
```

Customize the stop message with `middleware.message`. It accepts either a string or a callback that receives the blocked cooldown result:

```ts
import { Formatter } from 'seyfert';

const cooldownPlugin = cooldown({
    middleware: {
        message: (result) =>
            result.reason === 'over_capacity'
                ? 'This command cannot run with its current cooldown settings.'
                : `Try again ${Formatter.timestamp(result.retryAfter)}.`,
    },
});
```

If you use a custom middleware name, add a `middlewares` entry to `SeyfertRegistry` with `CooldownMiddlewares`:

```ts
import type { CooldownMiddlewares } from '@slipher/cooldown';

declare module 'seyfert' {
    interface SeyfertRegistry { middlewares: CooldownMiddlewares<'commandCooldown'> }
}

const cooldownPlugin = cooldown({
    middleware: { name: 'commandCooldown' },
});
```

## Custom Handling

You can still handle the result yourself when a command or middleware needs custom behavior. For a reusable policy, register your own Seyfert middleware and call `context.cooldown.context()` there:

```ts
import { createMiddleware, Formatter } from 'seyfert';

export const friendlyCooldown = createMiddleware(async ({ context, next, stop }) => {
    const result = await context.cooldown.context();

    if (!result || result.allowed) {
        return next(result);
    }

    return stop(
        result.reason === 'over_capacity'
            ? 'This command cannot run with its current cooldown settings.'
            : `Try again ${Formatter.timestamp(result.retryAfter)}.`,
    );
});
```

Then use that middleware like any other command middleware:

```ts
import { Command, type CommandContext, Declare, Middlewares } from 'seyfert';
import { Cooldown } from '@slipher/cooldown';

@Declare({ name: 'ping', description: 'Ping' })
@Cooldown.user(5_000)
@Middlewares(['friendlyCooldown'])
export default class PingCommand extends Command {
    async run(ctx: CommandContext) {
        await ctx.write({ content: 'Pong!' });
    }
}
```

You can also handle a one-off command directly:

```ts
import { Command, type CommandContext, Declare, Formatter } from 'seyfert';
import { Cooldown } from '@slipher/cooldown';

@Declare({ name: 'ping', description: 'Ping' })
@Cooldown.user(5_000)
export default class PingCommand extends Command {
    async run(ctx: CommandContext) {
        const result = await ctx.cooldown.context();

        if (result && !result.allowed) {
            return ctx.write({
                content:
                    result.reason === 'over_capacity'
                        ? 'This command cannot run with its current cooldown settings.'
                        : `Try again ${Formatter.timestamp(result.retryAfter)}.`,
            });
        }

        await ctx.write({ content: 'Pong!' });
    }
}
```
