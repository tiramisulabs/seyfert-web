# Stageshow kit

`kit/` is a copy of the [Stageshow](https://github.com/benjitaylor/skills/tree/main/stageshow) React kit (MIT, see `LICENSE`), without its bundled third-party brand marks (`brands/`, `BrandMark`). Treat it as vendored: restyle parts from the demo's own CSS rather than editing the kit, so it can be refreshed from upstream.

`seyfert.css` maps the kit's tokens to the observatory palette (`DESIGN.md`) for stages that sit on the space-void page. The demos themselves live in `components/stage-demos/`.
